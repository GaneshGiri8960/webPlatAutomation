# Automation Testing Project

## Instructions to Run Tests
1. Install Java and Maven.
2. Add Selenium and TestNG dependencies in `pom.xml`.
3. Update the ChromeDriver path in `BaseTest.java`.
4. Run `mvn test` or execute `testng.xml` in your IDE.

## Dependencies and Setup
- Selenium WebDriver
- TestNG
- Apache POI
- ExtentReports
- ChromeDriver
